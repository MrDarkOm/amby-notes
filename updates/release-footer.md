### Установка

| Система               | Что скачать                                       |
| --------------------- | ------------------------------------------------- |
| macOS (Apple Silicon) | `.dmg` с `aarch64` в названии                     |
| macOS (Intel)         | `.dmg` с `x64` в названии                         |
| Windows               | установщик `-setup.exe` или `.msi`                |
| Linux                 | `.AppImage` (обновляется сам, без пароля системы) |

Если Amby уже установлена и автообновление включено, новая версия поставится сама при
следующем запуске. Обновления подписаны: подделку приложение не установит.

# Amby — Следующая версия

## Новое

## Улучшения

- В настройках модулей убрана строка установки, удаления, экспорта и проверки версии: остались только переключатели включения. Модуль, удалённый в прежних версиях, возвращается автоматически.

## Исправления

- Встроенные модули (в том числе ИИ) снова устанавливаются кнопкой в «Настройки → Модули» без скачивания: их код уже входит в приложение, поэтому установка только отмечает модуль в реестре. Раньше она пыталась скачать пакет и могла завершиться ошибкой.

- Подключения ИИ теперь хранятся в отдельном файле `ai-connections.json`, а не внутри `settings.json`. Более старая сборка Amby, запущенная на тех же данных, больше не может их стереть: она по-прежнему читает свой прежний раздел в `settings.json`. При первом открытии настроек ИИ данные переносятся автоматически с резервной копией; настройки, которые стёрла старая сборка, восстанавливаются из прежнего переноса.

## Для разработчиков

- Удалена поддержка старых форматов, которых больше нет у пользователей. Файлы на диске не удаляются и не меняются, они просто перестают читаться: миграция баз (четыре команды `detect/preflight/execute/rollback_database_migration`), перенос значений из `.ambd/records` во frontmatter при открытии базы, диагностика проектов формата v2 (`amby-project.json`) и строка «Папки старого формата» в панели творчества, перенос скрытых колонок из localStorage в вид, миграция конфигурации модулей в `workspace.json` (файл без профиля получает стандартный профиль). Журналы ID-миграции старейшего вида (только список путей) по-прежнему пропускаются при проверке.
- Из `discovery.rs` убран неиспользуемый ремонт старых манифестов; манифест `ambd.json` теперь называется просто `DATABASE_MANIFEST`.

- В правила проекта добавлено: формат существующего ключа или файла настроек нельзя менять на месте, несовместимый формат хранится под новым ключом или в новом файле. Настройки выносятся в отдельные файлы только при конкретной причине.

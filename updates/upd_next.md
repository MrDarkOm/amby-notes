# Amby — Следующая версия

## Новое

- В настройках обновлений появился выбор канала: «Стабильный» получает только готовые релизы, «Бета» — также бета-сборки. Выбор применяется и к автоматическим обновлениям.

## Улучшения

- Проверка обновлений в настройках теперь расположена перед ссылкой на исходный код.

## Исправления

- Резервное копирование сервера синхронизации корректно сохраняет файлы в Windows.

## Для разработчиков

- Исправлена совместимость тестовых данных синхронизации с новым Clippy.
- При тайм-ауте теста переименования выводится состояние тестового сервера и клиента.
- При сбое теста уведомления о восстановлении записывается состояние этапов синхронизации.
- Тест восстановленной заметки больше не зависит от фонового прохода синхронизации; тест исчезновения папки хранилища пропускается в Windows, где такую папку нельзя переименовать.
- Подготовлена публикация подписанных лент обновлений по каналам и автоматическая нумерация установщиков Windows. Версия бета-сборки сохраняет привычный вид `0.1.9-beta.2`; переход на стабильный канал не понижает установленную версию.

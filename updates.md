# Обновления Amby

Здесь собраны понятные пользователям изменения, которые войдут в следующие версии Amby. Записи накапливаются до выпуска и публикуются вместе одним аккуратным списком.

## Следующая версия

_Пока нет новых записей._

## 0.1.1 — 2026-09-08

Первое накопительное обновление: Amby получил встроенную систему обновлений и публичный учёт изменений.

### Новое

- Добавлена система безопасных обновлений через GitHub Releases: приложение проверяет доступность новой версии и устанавливает только подписанные сборки.
- В общих настройках появился раздел «Обновления» с переключателем автопроверки, текущим номером версии и кнопкой ручной проверки.
- Во время загрузки и установки отображается понятный статус и прогресс. Перед автоматической установкой Amby запрашивает подтверждение перезапуска.
- Создан публичный журнал изменений `updates.md`, в котором улучшения накапливаются до следующего выпуска.

### Улучшения

- Настройка автообновления сохраняется глобально и синхронизируется между главным окном и отдельным окном настроек.
- Версии npm, Rust и Tauri теперь проверяются на совпадение перед сборкой релиза.

### Безопасность

- Пакеты обновлений проверяются встроенным публичным ключом; неподписанные или изменённые файлы не устанавливаются.
- Доступ к проверке, установке и перезапуску предоставлен только главному окну и окну настроек.

### Для разработчиков

- Добавлен GitHub Actions-процесс для накопительной сборки macOS, Windows и Linux, создания `latest.json` и публикации релиза только после успешного завершения всех платформ.
- Обычная локальная сборка не требует release-ключа: updater-артефакты включаются отдельной release-конфигурацией.
- Добавлены тесты настроек автообновления, расчёта прогресса и ограничений Tauri permissions.
- Закреплён накопительный процесс выпуска: каждое изменение добавляется в публичный журнал, а patch-версия повышается один раз перед явно запрошенными commit и push.

# Shared services map

Owns frontend boundaries and reusable non-UI logic. Keep workspace state in
[workspace hooks/stores](../components/workspace/MAP.md).

| Concern                                 | Owner / next route                                                                                                                                             |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Filesystem / IPC / browser fallback     | [storage map](storage/MAP.md); [storage.ts](storage.ts) is a facade                                                                                            |
| Generated IPC types and wrappers        | [bindings.ts](bindings.ts), generated by Rust Specta tests; never edit manually                                                                                |
| Modules, profiles, installation         | [modules map](modules/MAP.md)                                                                                                                                  |
| AI provider client/helpers              | [ai.ts](ai.ts); [Rust ai.rs](../../src-tauri/src/ai.rs) and [credentials.rs](../../src-tauri/src/credentials.rs) own native provider/credential behavior       |
| App updates                             | [app-updater.ts](app-updater.ts), [startup gate](../App.tsx), [settings-updates.tsx](../components/workspace/settings/settings-updates.tsx)                    |
| Logging / diagnostics                   | [logger.ts](logger.ts), [diagnostics.ts](diagnostics.ts), [debug/](debug/)                                                                                     |
| Debug privacy / reports / health        | [debug/privacy.ts](debug/privacy.ts), [debug/report.ts](debug/report.ts), [debug/health.ts](debug/health.ts), [debug/health-bridge.ts](debug/health-bridge.ts) |
| Recovery drafts / per-key serialization | [recovery-drafts.ts](recovery-drafts.ts), [per-key-queue.ts](per-key-queue.ts); [save lifecycle](../components/workspace/autosave/MAP.md)                      |
| Canvas / Excalidraw format              | [canvas-format.ts](canvas-format.ts), [sketch-format.ts](sketch-format.ts)                                                                                     |
| Appearance / localization               | [themes.ts](themes.ts), [i18n.ts](i18n.ts); [appearance map](../themes/MAP.md)                                                                                 |
| Motion / shared helpers                 | [motion.tsx](motion.tsx), [motion-config.ts](motion-config.ts), [utils.ts](utils.ts), [async-disposable.ts](async-disposable.ts)                               |

Boundary tests live here: localization, themes, motion, Tauri permissions/build
config, vault scoping and bindings. For broad architecture changes use them in
addition to the tests beside the changed owner. Never expose credentials or note
contents in diagnostics. Updater changes require native packaging verification;
see [update-system.md](../../docs/update-system.md).

# Tooling map

The command source of truth is [package.json](../package.json), not copied
command lists in historical plans. Use Node.js 20.19+ or 22.12+, npm 10+, and Rust.

Local emoji resources: `npm run emoji:prepare` ([prepare-noto-emoji.mjs](prepare-noto-emoji.mjs)) imports a
pinned official Noto/Unicode release, verifies checksums and generates the manifest,
picker additions and shipped licenses. Search vocabulary: `npm run emoji:prepare-search`
([prepare-emoji-search.mjs](prepare-emoji-search.mjs)) imports pinned CLDR annotations
and licenses with source checksums. See [contract](../docs/emoji-icons.md).
SVG optimization uses pinned SVGO (development dependency only), preserves license
comments and records both original Git blobs and optimized output hashes. No Python is needed.

`npm run verify` aliases the full gate, including formatting, Knip, Rust checks,
tests and binding drift. `verify:fast` is for iteration. Every completed batch
still requires `npm run build`; do not weaken checks to make a batch pass.

For releases read [the cumulative release rules](../docs/ai/agent-guidelines.md#public-change-log-and-cumulative-releases)
and [update-system.md](../docs/update-system.md). Every change updates
[upd_next.md](../updates/upd_next.md), but ordinary changes do not bump a version.
Build outputs and machine-specific benchmark evidence must not be committed.

The [root Cargo workspace](../Cargo.toml) shares `target/` across `amby-core` and the desktop app.
Run `cargo test --locked -p amby-core` for core tests or `npm run rust:test` for both crates.
The [Rust CI gate](../.github/workflows/verify.yml) checks the standalone core on each platform
and checks its dependency tree for Tauri. Sync keeps its own workspace and target directory.

Branches move only through [promote.mjs](promote.mjs) (`npm run promote -- beta|main`): it
merges `dev` → `beta` or `beta` → `main` and removes the development files listed in
[dev-only-paths.txt](dev-only-paths.txt), which exist only on `dev`.

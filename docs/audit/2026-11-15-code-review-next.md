## Как работать

1. Прочитать `AGENTS.md` (правила проекта) и для каждой находки — её описание в отчёте.
   Номера строк в находках — на 2026-11-15; после уже сделанных исправлений они могли сместиться. Искать по
   имени функции или фрагменту кода и сначала убедиться, что проблема всё ещё есть.
2. На каждую находку: сначала тест, который падает на текущем коде; потом исправление; тест зелёный.
3. Проверки: `npm run typecheck`, `npm run lint`, `npx vitest run --maxWorkers=3`, `npm run build`; для Rust —
   `npm run rust:test`, `npm run rust:clippy`; для `sync/` — `npm run sync:test` и
   `cargo clippy --manifest-path sync/Cargo.toml --workspace --all-targets -- -D warnings`.
4. Запись на русском в `updates/upd_next.md` (раздел без изменения версии). Каждое исправление — отдельный
   коммит в `dev`. Push и теги — только по отдельной просьбе владельца.
5. Изменение команд IPC и типов, которые идут в `src/lib/bindings.ts`: навык `amby-ipc-change`. Видимые тексты:
   навык `amby-ui-strings`.

### TREE-01 — удалённая папка без заметок остаётся в дереве (Medium, S–M)

Симптом: после удаления папка висит в дереве; повторное удаление — «Не удалось удалить 1 из 1», в журнале
`file.delete_failed` с `failureCode: notFound`. На диске папки уже нет (ушла в корзину), синхронизация отметила её
удалённой. После перезапуска призрак пропадает: дерево при старте читается с диска.

Условие: в папке нет `.md`, `.canvas`, `.excalidraw` — пустая папка или папка мастерской (только `.json`).

Цепочка (найдено по коду, тестом не воспроизведено):

1. `recycle_bin.rs`, `collect_markdown_paths`: в `deleted_paths` идут только файлы `.md`/`.canvas`/`.excalidraw`;
   сама папка туда не попадает. Для такой папки список пуст.
2. `commands/mutations.rs`, `sync_mutation_result` → `tree_patch_for(..., &mutation_paths(&result))`: путей нет.
   `vault/tree_patch.rs`, `patch_for_paths` на пустом входе возвращает `Some(TreePatch { ops: [] })` — «изменений
   нет» вместо `None` («перечитай»).
3. `workspace-orchestration.tsx`, `applyMutationResult`: патч есть → `patchTree` применяет ноль операций и
   возвращает `true` (`use-vault-data.ts`); запасной `applyTreePatch` не вызывается (и он тоже смотрит на пустой
   `deletedPaths`).
4. Наблюдатель не спасает: `delete_item_inner` через `prepare_write` заранее помечает исчезновение папки как свою
   запись.

Заодно: в индексе (`project_workshops` в `notes.db`) запись удалённой мастерской остаётся — проверить, что
удаление папки мастерской убирает её из каталога.

Направление: в результат удаления класть путь корня (`preview.original_path`) — например, в `also_touched`, —
чтобы патч убирал саму папку; пустой патч при непустой мутации считать «не знаю» (`None`). Тест сначала:
удаление пустой папки и папки только с `.json` убирает её из дерева без перезагрузки (Rust: патч содержит `Remove`;
фронт: строки в дереве нет). То же проверить для архива (`archive_item_inner`) и постоянного удаления.

### TREE-02 — настройка «Клик по папке только разворачивает её» (новое, S–M)

Сейчас клик по имени папки в дереве открывает её вкладкой-карточкой (коллекцией): `tree-row.tsx` → `onSelect` →
`use-collection-folder-select.ts` (папка мастерской открывает мастерскую) → `use-document-loading.ts`
`handleSelect`/`openTreeItem`. Разворачивает и сворачивает только шеврон (`onToggleOpen`).

Нужно: переключатель в настройках (раздел «Файлы» рядом с режимом удаления, `settings-data.tsx`; поле в
`prefs.files` в `app-config.ts` с нормализацией и значением по умолчанию — как сейчас, то есть открывать).
Включён → клик по папке только разворачивает/сворачивает её в дереве, без вкладки и без открытия мастерской.
Открыть карточку папки по-прежнему можно из контекстного меню («Открыть в новой вкладке» и т. п.).

Уточнить при реализации: Enter/пробел с клавиатуры (`use-tree-keyboard.ts`) ведут себя так же, как клик; Cmd/Shift
по-прежнему выделяют, а не разворачивают; «папка» с собственной заметкой (`Имя/Имя.md`) — это заметка, она
открывается как раньше. Тексты — через навык `amby-ui-strings` (все языки). Тесты: настройка по умолчанию не меняет
поведение; включённая — клик меняет `aria-expanded` и не создаёт вкладку.

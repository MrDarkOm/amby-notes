## Следующий заход — семь Medium ближе всего к данным (по порядку)

Каждое: сначала красный тест, потом исправление, отдельный коммит, запись в `updates/upd_next.md`.

1. **SAVE-07** — `src-tauri/src/commands/notes.rs` `write_note`: `prepare_note_write_from_path` (сверка
   ревизии и слияние frontmatter) идёт до `mutation_gate`; `commit_prepared_note_write` — под ним. Перенести
   подготовку под тот же замок, как в `write_file`. Тест: запись свойств или восстановление между чтением и
   коммитом не должны затираться старой шапкой (смоделировать через вызов подготовки, затем изменение файла,
   затем коммит → ожидать конфликт). Не держать замок SQLite дольше нужного.
2. **SAVE-06** — `workspace-orchestration.tsx` `refreshLocalVault` (~470): заменяет буферы по снимку
   `unsavedFileIds`, сделанному до цикла, читает по `id` вместо `noteId`, глотает ошибки. Использовать ту же
   сверку, что у наблюдателя (`use-vault-data.ts`, свежая проверка `unsavedFileIds` и
   `hasUnsavedAutosave` после каждого `await`, конфликт при грязном буфере), `logger` с кодом.
3. **SAVE-08** — `src/lib/recovery-drafts.ts`: сбой записи черновика уходит только в `console.warn`; сбой
   чтения возвращает `null` молча. Нужен `logger` с `failureCode` и предупреждение на карточке заметки
   (новый ключ локали, тексты через навык `amby-ui-strings`).
4. **CRE-01** — `sketch-editor.tsx:262-287` / `sketch-format.ts` `serializeSketch`: при первой правке теряются
   неизвестные верхние поля и `source`. Хранить разобранные верхние поля в ref и подмешивать (как
   `canvasTemplateRef` у холста). Заодно проверить `sketch-editor.tsx:203-207` (фон `#ffffff` → `transparent`).
5. **CRE-02** — `src/lib/canvas-format.ts:188-197,276`: узел неизвестного типа сохраняется как
   `type:"text", text:""`. Хранить исходный узел как есть (заглушка только для чтения); не округлять
   координаты нетронутых узлов.
6. **SHELL-01** — `workspace-orchestration.tsx:896`, `use-document-mutations.tsx:295,332,396`: откат
   отменённого переноса пишет «отображаемое» дерево (с подмешанными иконками и типами слоя) в сырое.
   Брать для отката сырое дерево.
7. **SYNC-01** — `sync/core/src/engine/apply.rs:436-451` → `:601`, `src-tauri/src/sync/vault_fs.rs:383-420`:
   хеш локального файла проверяется до загрузки тела, при публикации — нет. Передать ожидаемый хеш в
   `StagedWrite::publish`, при расхождении `FsError::Changed` → `plan.hold_before(seq)` (как путь С9).
   Для файла, нового с сервера (`existing == None`), публикация не должна заменять появившийся файл.
   Тест в симуляторе: «правка во время `RemoteKind::Download`», сначала красный. Тесты:
   `npm run sync:test` (весь workspace) и `cargo test --manifest-path src-tauri/Cargo.toml sync::`.

## Что выяснилось на практике (важно для следующей сессии)

- Каждое новое событие `logger.*` / `tracing::warn!(event = …)` нужно добавить **в оба** белых списка:
  `src-tauri/src/logging.rs` (`ALLOWED_EVENTS`) и `src/lib/debug/event-codes.ts`. Иначе падает
  `src/lib/debug/event-registry.test.ts`. После правок Rust гонять и vitest.
- Не запускать отладочный бинарник `src-tauri/target/debug/amby-notes` вручную: при старте он перезаписывает
  `src/lib/bindings.ts`, и Vite перезагружает открытое dev-окно (так в прошлый раз появился ложный
  «черновик после сбоя»).
- Инструмент управления окнами не отличает тестовую сборку от установленного Amby (один идентификатор
  `amby-notes`) — не использовать его для нативных проверок, чтобы не трогать настоящее хранилище.
  Нативную проверку просить у владельца (`npm run tauri dev`, тестовое хранилище).
- Если Mac засыпает, полный vitest падает случайными тестами с длительностью ~900 с. Перезапустить
  упавшие файлы отдельно; полный прогон повторить, когда машина не спит.
- Правки через Python-скрипты: искать границы заменяемого куска только **после** начала (`s.index(x, start)`),
  проверять число строк файла после правки.
- Изменяющие команды git в авто-режиме писать как `rtk git …`. Коммиты заканчивать строкой
  `Co-Authored-By` из системного напоминания текущей сессии. Push и теги — только по отдельной просьбе.

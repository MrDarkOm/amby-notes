# Подложка и размеры иконки Amby

Дата: 2026-09-24

## Причина

На macOS приложение использовало два представления значка. Закрытое приложение показывало `icon.icns` из пакета с системной серой подложкой, а после запуска код в `state.rs` задавал Dock-иконку из `icon.png`. Исходный SVG включал собственную тёмную плитку и широкий прозрачный отступ, поэтому два состояния выглядели по-разному. Изменение одного `viewBox` не устраняло разницу форматов.

## Исходник и решение

- Переданный пользователем файл `AmbyNotes.png` фактически является SVG. Его байты сохранены без изменений в `src-tauri/icons/amby-mark.svg`. Пути, цвета и пропорции рисунка не меняются.
- Для macOS-пакета генерируется `icon.icns` с тёмной плиткой 840 × 840 px по центру прозрачного холста 1024 × 1024 px. Такой размер соответствует соседним значкам в Dock; рисунок масштабируется вместе с плиткой без изменения пропорций. При запуске macOS использует совпадающий `icon-macos.png`. Для Windows/Linux остаётся полноразмерная плитка `icon.png` с тем же градиентом.
- В размерах до 32 px весь исходный рисунок увеличен внутри подложки без удаления или перерисовки деталей. Остальные размеры используют обычную композицию.
- `node scripts/generate-app-icons.mjs` создаёт все desktop PNG, ICNS, ICO и Windows Square/Store assets из одного SVG. Он сохраняет фиксированный порядок слоёв ICNS и ICO, чтобы повторная генерация была воспроизводимой.

## Проверка

Проверить, что копия вектора совпадает с присланным файлом; что Mac ICNS и runtime PNG имеют одинаковую плитку 840 × 840 px с прозрачными внешними полями; что ICO содержит слои 16, 24, 32, 48, 64 и 256 px. После сборки `.app` сверить вложенный ICNS и PNG в исполняемом файле. Перед выпуском сравнить значок в Dock у закрытого и запущенного приложения, а также в Windows shell и Linux launcher.

Основа выбора Mac-подложки: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons) описывает квадратный холст 1024 × 1024 px и маску скруглённого прямоугольника; [AppKit](https://developer.apple.com/documentation/appkit/nsapplication/applicationiconimage) описывает отдельное изображение для иконки запущенного приложения. Размер плитки 840 px подобран по сравнению с соседними значками на снимке Dock.

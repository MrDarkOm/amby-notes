## Правила (кратко)

- Тесты до кода, сначала красные; для движка, слияния, сервера и криптографии тесты замораживаются на время кода.
  Спорный замороженный тест — не менять молча, спросить владельца.
- Ветки `sync/*` от **локальной** `dev`, вливание `git merge --no-ff`, только локальные коммиты.
- Перед вливанием ветки: `npm run typecheck`, `npm run lint`, `npm run docs:check`; после — `npm run verify` и
  ядро `sync/` в release (тесты симуляции в debug очень медленные).
- `updates/upd_next.md` по-русски на каждое заметное изменение; конфликт в нём — оставить обе стороны.
- Никогда не править `src/lib/bindings.ts` руками (`npm run rust:test` пересоздаёт).
- Отвечать владельцу по-русски, просто и коротко; данные — превыше всего.

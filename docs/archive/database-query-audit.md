# Аудит запросов баз данных — 2026-09-05

## Устройство хранения

Markdown-заметка представляет строку базы; `amby-id` связывает её со значениями.
`ambd.json` хранит схему, а `.ambd/records`, `.ambd/views` и `.ambd/templates` —
переносимые значения, представления и шаблоны. Эти файлы являются исходными
данными. SQLite `.amby/notes.db` содержит основной индекс заметок и производные
таблицы `db_*` для запросов. Локальные свойства обычных заметок отдельно
сохраняются в `.amby/properties.json`.

Frontend обращается к storage/IPC. Rust выполняет discovery, проверку формата,
CAS-записи и публикацию SQLite-проекции. Включение модуля баз перестраивает
проекцию. При ошибках discovery существующий индекс сохраняется и получает
статус `staleReadOnly`.

## Исправления

- `contains` и `startsWith` раньше завершались ошибкой SQLite: `ESCAPE`
  содержал два символа. Теперь экранирование корректно, а `%`, `_` и `\`
  в поисковом тексте сравниваются буквально. Значения остаются SQL-параметрами.
- Постраничная загрузка использовала BLOB-курсор даже для числовых SQL-ключей,
  теряла различие между NULL и пустой строкой и игнорировала `nulls`.
  Курсор теперь сохраняет тип каждого ключа; сортировка и продолжение страницы
  одинаково учитывают NULL, направление и устойчивый `noteId` tie-breaker.
- Из нескольких правил сортировки применялось только первое. Теперь запрос
  учитывает все правила по очереди, включая разные направления. Лимит —
  32 правила; неподдерживаемые типы возвращают `invalidSortField`.
- Побайтовые ключи отрицательных decimal неправильно сравнивали префиксы:
  `-1.2` оказывалось меньше `-1.23`. Терминатор исправляет обратный порядок.
  Числовые `equals`/`notEquals` теперь используют нормализованный точный ключ,
  поэтому `-1.200` и `-12e-1` равны без преобразования в floating point.
- Relation проверяла принадлежность целевой строки исходной базе. Теперь
  используется `config.targetDatabaseId`; сохраняются различия `resolved`,
  `outsideDatabase` и `missing`.
- Чтение диагностик ошибочно декодировало JSON дважды и теряло путь и сообщение.
  Теперь оба поля доходят до результата запроса.

Изменены только `database/query.rs` и `database/projection.rs`; ранее начатые
изменения остальных частей модуля сохранены.

## Данные и совместимость

Форматы Markdown, frontmatter, manifest и shards не меняются. Миграции
пользовательских данных нет. Новые decimal-ключи и статусы связей создаются
при обычном перестроении производной проекции. Старые курсоры возвращают
`staleCursor`; клиент должен начать загрузку с первой страницы. IPC-типы не
менялись, сгенерированный `bindings.ts` воспроизведён побайтно.

## Проверки

Добавлены восемь Rust-тестов: текстовые фильтры, типизированная пагинация,
несколько сортировок, числовые фильтры, некорректные курсоры, диагностики,
порядок decimal и восстановление relations. Четыре первоначальных регрессионных
теста сначала воспроизвели ошибки на исходном коде.

- Все 57 тестов модуля `database::` проходят.
- `npm run verify`: TypeScript, ESLint, 463 Vitest, Prettier, Knip, Rustfmt,
  strict Clippy и 265 Rust-тестов проходят; один large-vault тест явно ignored.
- Финальный `bindings:check` возвращает ошибку из-за уже существовавшего
  незакоммиченного diff `src/lib/bindings.ts` относительно HEAD. Сравнение с
  копией файла до аудита подтверждает, что генерация его не изменила.
- Browser smoke: `npm run dev`, запуск интерфейса и открытие приветственной
  заметки проверены. Это проверка web fallback, а не SQLite.
- `npm run test:storage:live`: frontend и Tauri test binary собираются,
  но WebView-сценарий не вернул `AMBY_NATIVE_RESULT` за 120 секунд даже при
  запуске вне sandbox. Native smoke не считается PASS; полноценная проверка
  через Tauri UI остаётся открытой.

## Следующий отдельный этап

После исправления корректности запросов нужен замер больших баз: текущие
команды после записи значения запускают полное перестроение проекции vault.
Переход к обновлению только затронутых строк требует отдельной проверки
watcher-событий, инвалидирования курсоров и восстановления после ошибок.
Этот аудит не закрывает весь продуктовый backlog в `Road/DB Roadmap.md` и
не является подтверждением production readiness на всех платформах.

# Архив устаревшей документации Amby Notes

В этот каталог перемещены исторические документы, отчёты о завершённых контрольных точках, устаревшие планы дорелизных версий и промежуточные диагностические материалы.

Эти материалы сохранены для справки и истории разработки, но **не являются актуальными контрактами или действующими спецификациями приложения**.

---

### Корневой архив (`docs/archive/`)

- **`codex-handoff.md`** — Ранний технический handoff разработчиков от 2026-08-04 (коммит `d326f45`).

- **`roadmap-progress.md`** — Хронологический журнал стабилизации архитектуры (Фазы 0–6) от 2026-08-31.
- **`release-readiness.md`** — Исторический отчёт готовности релиза 0.1.0 (FINAL-02) от 2026-08-31.
- **`release-1.0-checklist.md`** — Чек-лист кандидата релиза `974ff43` от 2026-09-01.
- **`database-query-audit.md`** — Аудит запросов баз данных от 2026-09-05 (описывал устаревшую архитектуру с файлами `.ambd/records/` до перехода на Frontmatter-First).

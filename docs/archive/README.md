## Завершённые планы октября 2026

Пути — как они лежали в `docs/` до удаления.

### Плоская мастерская творческого модуля (`docs/creative-workshop-plan.md`, 13–14 октября)

Этапы 0–8 выполнены. Решение: формат v2 строил принадлежность на вложенности папок, и
спорные места возникали на стыке «общий раздел вселенной / свой раздел истории». В v3
у каждой вещи своя база, принадлежность задаётся только связью (Relation по ID заметки),
вложенность осталась в одном месте — страницы текста лежат в своей истории. Миграции
v2→v3 нет (пользователей у v2 не было). Решения W1–W12 (одна мастерская на хранилище,
папка по умолчанию «Мастерская», все базы создаются сразу при инициализации и т. д.)
перенесены в контракт. Не проверено руками в нативном окне только то, что перечислено
в [native-ui-smoke.md](../native-ui-smoke.md). Контракт: [creative-format.md](../creative-format.md).

### Паритет баз данных с Notion (`docs/notion-database-parity-audit-2026-09-30.md`, `docs/Road/database-notion-parity-plan.md`, 30 сентября – 3 октября)

Аудит нашёл главный разрыв между доменной моделью и законченными сценариями (Relation,
Rollup, Gallery существовали, но не были доведены). Порядок работ: надёжность операций →
страница записи и свойства → Relation и Rollup → сохранённые представления → Gallery/
Board/List → проект со своими задачами. Этапы 0–4 выполнены коммитом `5db7738`
(2026-10-02), правки по четырём ручным проверкам, панель настроек вида, собственный select
и редактор свойств — `fc242a5` (2026-10-03). Открытые дефекты стабилизации баз остаются в
[database-stabilization-codex-audit.md](../Road/database-stabilization-codex-audit.md).
Контракты: [database-format.md](../database-format.md), [database-frontend.md](../database-frontend.md),
[database-user-flows.md](../database-user-flows.md).

### Debug-режим (`docs/Road/debug-mode-plan.md`, `-orchestration.md`, `-acceptance.md`, 27 сентября)

Реализован (пакеты D-00…D-60): настройка сбора, структурированные события frontend и Rust,
реальное состояние приложения, история сессий, цепочки операций с длительностью,
безопасный экспорт отчёта без личных данных. Не закрыты были два пункта приёмки:
проверка bindings требовала чистого Git diff, а один сценарий native trash расходился с
текущим удалением. Код: `src/lib/logger*`, `src/lib/diagnostics*`, `src-tauri/src/logging.rs`,
`src-tauri/src/commands/debug.rs`; карты — [../../src-tauri/src/MAP.md](../../src-tauri/src/MAP.md).

### Подложка и размеры значка (`docs/Road/app-icon-revision-plan.md`, 24 сентября)

На macOS закрытое и запущенное приложение показывали разные значки. Решение: исходник —
SVG, `icon.icns` с тёмной плиткой 840×840 по центру прозрачного холста 1024×1024.
Реализовано; файлы значков — `src-tauri/icons/`.

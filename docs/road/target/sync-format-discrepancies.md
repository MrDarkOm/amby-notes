# Discrepancies between docs/sync-plan.md and the code (found while writing docs/sync-format.md)

The doc follows the CODE. Cryptographic layouts (appendix А: Ф1-Ф34) matched the code and the Python
reference with no differences. Differences are in protocol detail, mostly because later appendices
refined earlier tables that were not updated.

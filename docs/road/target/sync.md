## Как начинать новую сессию

- Прочитать этот файл, затем только нужный раздел плана: этапы — раздел 6, свойства — приложение З.
- Порядок работы — раздел 6 плана «Сначала тесты». Строгие части: отдельная сессия красных тестов → коммит
  тестов с одобрения владельца → отдельная сессия кода, тесты заморожены. Облегчённые (интерфейс): тесты
  первым коммитом, потом код.
- Новые правила сначала записываются в план (решения с номером и датой), спорное для пользователя —
  вопросом владельцу. Работа в ветке от `dev`, вливание в `dev` без squash, когда этап зелёный.
- Коммиты, вливание, пуш и выпуск — только с одобрения владельца.

## Порядок (решение владельца, 5 ноября; уточнено 6 ноября)

Пункт 1 делает владелец; он не останавливает пункты 2 и 3 — правила и тесты для них пишутся параллельно.

1. **Ручная проверка свойств на двух компьютерах — закрыта 13 ноября (решение владельца: пройдена 6–7 ноября, отдельный просмотр уведомлений не нужен).** (делал владелец, на копиях хранилищ: при первом
   открытии хранилище само переходит на новый формат). Сценарий: правка оформления на одном компьютере
   (иконка, цвет варианта, варианты, тип) видна на другом; одновременные правки оформления у разных
   заметок сливаются без конфликта; одновременная правка одной и той же заметки; переименование свойства;
   старая версия приложения на втором компьютере. Найденное — в ветку исправлений от `dev`.
2. **Э5: прежние версии и удалённые файлы — сделано** (приложение И, `259cbae7`): версии — в истории
   заметки, удалённые — разделом «На сервере» в архиве.
3. **Лимит файла 30 МБ** (решение владельца, 11 ноября 2026): Amby — заметник, поддержка больших
   файлов не требуется. Предельный исходный размер одного синхронизируемого файла — 30 000 000 байт;
   зашифрованное тело требует отдельного запаса на служебные данные. Вместо снятия ограничения через
   потоковое шифрование согласовать проверки клиента, сервера и сообщение в интерфейсе. Файл больше
   лимита не удаляется из хранилища, а остаётся в «Не синхронизируется». **Реализован в коде:**
   предел движка 30 МБ; на боевом сервере применён предел зашифрованного тела 30 416 160 байт. Работу по поддержке файлов крупнее 30 МБ из очереди убрать.
4. **Э5: удаление пространства с сервера из приложения — реализовано 12 ноября** (приложение Л плана):
   `DELETE /v1/spaces/{id}`, клиент, runtime, команда `sync_delete_space`, действие «Удалить с сервера…»
   с вводом точного названия. Удаляется только серверная копия и её версии; **локальные файлы на всех
   устройствах остаются**, обмен с удалённым пространством останавливается, другие устройства
   выключают его сами. Тесты коммитом раньше кода. **Развёрнуто на Omlet 12 ноября:** образ
   `delete-space-20261112`, резервная копия `pre-delete-space-20261112`, схема 2 и счётчики таблиц без
   изменений. Нативная проверка двух окон (`test:native:sync-vault`, локальный сервер) — 28/28.
   Проверка на двух физических компьютерах (Mac и Windows, боевой сервер, тестовое пространство)
   пройдена 12 ноября: заметка и несохранённая правка на Windows сохранились, Windows сам выключил
   обмен (`enabled=0`) и после перезапуска не возобновил его. Замечания: на Windows удаление
   показано как ошибка с «Повторить»; в журнале `sync_pass_failed` без кода причины; в
   подтверждении размер пространства был «0 Б» — все три исправлены (`f49d2773`). Мутационная
   проверка удаления: сервер 1 пойман / 4 не собираются, клиент 1/1 пойман, выживших нет.
   Отчёт тестов: [sync-delete-space-tests.md](sync-delete-space-tests.md).
5. **Э2б без QR**: открытая регистрация реализована в коде (11 ноября): настройка выключена по умолчанию,

## Подписка (13 ноября, решение владельца)

Регистрация открыта, но синхронизирует только аккаунт с подпиской; без неё аккаунт есть (логин, имена
устройств, пароль), данные на сервере можно читать, возвращать и удалять, отправка закрыта. Подписку
выдаёт и снимает администратор (`user plan set <имя> <тариф> [--until YYYY-MM-DD]`, `--default`),
кнопка покупки в приложении — заглушка. Правила — приложение Н плана (Н1–Н12). **Развёрнуто на Omlet 13 ноября:** образ
`subscription-20261113` (`dev` `ecd14e56`), резервная копия `pre-subscription-20261113`, схема 2 → 3
(копия `pre-v3-*`), счётчики таблиц без изменений; тариф по умолчанию `free` (без синхронизации), подписка —
`notes` (1 ГБ, файл до 30 МБ), прежние аккаунты остались на `legacy`. Пройдены 21 проверка API на копии и
через публичный HTTPS; временные аккаунты и тестовый контейнер удалены. Исправление Б3 (приложение Т) развёрнуто
тем же днём: образ `fix-b3-20261113` (`dev` `7480f1bb`), копия `pre-fix-b3-20261113`, схема 3 без изменений,
22 проверки на копии и через HTTPS. Пределы сервера (приложение Х: запас места 1 ГиБ,
вход до 64 КиБ, не больше 4 больших тел, удаления без подписки только существующего) развёрнуты тем же днём:
образ `limits-20261113` (`dev` `0bc82828`), копия `pre-limits-20261113`, 25 проверок на копии и через HTTPS.
Тарифу `notes` задан предел истории 1 ГБ (`max_history_bytes`). Оплата, вход через
Google и Apple по-прежнему отложены.

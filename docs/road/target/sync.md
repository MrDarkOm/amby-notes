# Синхронизация: что осталось

План и решения: [../../sync-plan.md](../../sync-plan.md). Сделано: Э0–Э4б, приложение Е, ворота, настоящие
хранилища (27 октября), сервер владельца, ключ и токен одной записью в связке ключей, ручная проверка на двух
компьютерах.

## Э2б. Регистрация и устройства

- Открытая регистрация на своём сервере (настройка, по умолчанию выключена). Сейчас интерфейс пишет
  «регистрация по коду приглашения».
- Имя устройства после входа: `device.name_enc` в `login` и `recover` станет необязательным.
- Подключение нового устройства по QR со старого. Владелец: не нужно, пока нет мобильного приложения.

## Э5. Завершение

- Просмотр и восстановление прежних версий файла с сервера; возврат удалённого файла.
- Удаление пространства с сервера из приложения (сейчас только команды администратора сервера).
- Потоковое шифрование тела: файлы больше 256 МБ пока в списке «Не синхронизируется» (Д71).
- Публичная документация для своего сервера и контракт `docs/sync-format.md` (файла ещё нет).
- Проверка безопасности всего этапа. Публикация Docker-образа и релиз только по отдельному разрешению.

## Приложение Ж

Слияние `.amby/properties.json` по ключам заметок. Сейчас такой конфликт остаётся конфликтом всего файла.
Описание принято Opus, тесты (`sync/props-tests`) не написаны.
